# 一箭又一箭
基于 Python + Pygame 的点击式箭头解谜小游戏。

## 开发环境
- Python 3.13
- Pygame

## 运行方法
1. 安装依赖：`pip install pygame`
2. 运行游戏：`python main.py`

## 操作说明
- 空格键：开始游戏 / 进入下一关
- 鼠标左键：点击箭头
- R键或右上角按钮：重置当前关卡
